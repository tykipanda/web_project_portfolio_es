# Portafolio personal

Mi portafolio personal, creado a partir de un diseño de Figma para el sprint 4 de TripleTen. Aquí muestro quién soy, mis habilidades, los proyectos que he hecho y cómo contactarme.

**Ver el sitio:** https://tykipanda.github.io/web_project_portfolio_es/

## Funcionalidad

- Presentación personal con foto, descripción y enlaces a mi CV, GitHub y contacto.
- Sección de habilidades y herramientas con los lenguajes y herramientas que uso.
- Tarjetas de proyectos destacados con enlaces a la demo y al código.
- Sección de contacto con correo y redes sociales.
- Diseño adaptado a escritorio (1440 px), tablet (768 px) y móvil (320 px).
- Estados hover en todos los elementos interactivos.

## Tecnologías y técnicas

- HTML5 semántico y metodología BEM.
- CSS3: Flexbox, Grid y media queries (puntos de ruptura en 1023 px y 767 px).
- Degradados lineales y radiales para el velo de las tarjetas y las manchas de luz del fondo.
- Fuentes locales con `@font-face` (Open Sans y Archivo Black).
- Git y GitHub para el control de versiones; GitHub Pages para la publicación.
